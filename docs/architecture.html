AeroAndes Voice Agent

Flight changes by phone for a LATAM airline BPO · Architecture

One call, step by step

  1. The caller dials the Twilio number and a small router function sends the call to the agent. Reviewers can use the web link instead.
  2. At call start, ElevenLabs calls the initiation webhook with the caller's number. The API maps the prefix to a country and returns the voice, the greeting and the variables.
  3. The agent verifies booking code and surname on every tool call, then searches flights. Fees come already priced by the rules in code, never by the LLM.
  4. The deterministic procedure reads the change back, waits for a yes and calls cambiar_vuelo with confirmacion_cliente: true. Firestore commits it in a transaction and the caller gets an SMS payment link.
  5. The call ends with end_call, or goes to a human advisor if the caller accepts the offer.

Cloud Scheduler resets the demo data every hour, so every reviewer finds booking K7Q2MX in its original state even after someone else has changed the flight.
